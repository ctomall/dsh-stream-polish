Agent Dev Loop / 验证流程

把“编辑 → 全量验证”的循环，压成一条流水线

同一段 UI 插件工作：5 次页面加载 + 2 次 19s 真等 + 2 次读图 + 1 次返工，可以压到 1 次加载 + 假时钟 + 1 张图。省的不是打字，是重复启动、真实等待和返工。
